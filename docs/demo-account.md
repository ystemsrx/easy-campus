# Demo account

微信审核体验账号：`demo`，密码：`123456`。

该账号仅在小程序内登录，不创建后端用户，不调用校园身份认证，也不持有后端可用的令牌。首页固定显示“晚上好，同学”。正式账号继续使用原有登录和数据路径。

`miniprogram/demo/` 提供课表、日程、成绩、考试、校园消息、学校通知、公告、电费、空教室、校历和选课助手的示例数据。每次冷启动和本地日期变化时，在页面读取缓存前重新填充示例快照；课程覆盖一周七天，日期跟随当前日期生成，假期及未来年份也有可浏览内容。同一天的日程编辑、电费换绑、已读、点赞和课程想法保留在 demo 独立的本地状态中，跨天恢复新示例。

课表提供完整的 12 节示例时间，课程分布在上午、下午和晚上，连续课长为 1～4 节。以当前周一的日期为种子打乱课程和每日安排，同一周内刷新、重启和切换页面保持一致，新的一周重新排列；课程不重叠，也不跨午休或晚饭时段。

统一请求层在设备注册、签名和网络调用前处理 demo 请求。反馈等提交直接返回本地结果；未实现的请求在本地失败，不回退到真实接口。校历在本地绘制，且不覆盖正式账号的校历文件缓存。附件下载的签名路径也禁止 demo 使用。

自动查寝的可见性不受服务端开关或旧缓存影响；demo 入口始终展示。打卡状态、地点、套餐、额度和历史订单均为本地示例，每天更新。开关、协议和购买操作仅修改 demo 状态，购买直接返回本地成功订单，不调用微信登录或支付。历史订单页使用独立路径 `features/pages/auto-dorm-check-orders/index`，可体验分页、退款状态与复制订单号。

demo 选课助手隐藏“学长学姐说”板块，发布想法保留评分和关键词选择，不显示“真心话”输入框或已发布想法的正文。选择评分和 1～5 个关键词即可在本地发布，旧草稿正文不会带入提交；正式账号仍使用原有页面和正文校验。

验证：`npm run check:demo`、`npm run check:orders`，以及完整的 `npm run check`。回归检查覆盖无网络登录、所有读写功能、错误密码、未知接口、跨天/跨年/闰日、缓存恢复、账号隔离、自动查寝入口及历史订单。
