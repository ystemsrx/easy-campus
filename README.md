# Easy Campus

一站式校园助手

[![License](https://img.shields.io/badge/license-AGPL--3.0-blue)](LICENSE)

</div>

## 简介

Easy Campus 将常用的校园信息与服务集中在一个简洁的入口中，帮助学生更方便地查看课程、成绩、考试和校园通知，减少在不同系统之间反复查找的麻烦。

## 功能

| 功能     | 说明                                             |
| -------- | ------------------------------------------------ |
| 首页     | 汇总今日课程、校园消息和常用入口                 |
| 课表     | 查看每周课表、课程时间与地点                     |
| 成绩     | 按学期查看、搜索和排序成绩，了解成绩详情与通过率 |
| 考试     | 查看考试安排、时间、地点和考试类型               |
| 消息中心 | 集中查看公告、站内通知与未读消息                 |
| 校园消息 | 集中查看调课、补课、停课等教学消息               |
| 学校通知 | 搜索并阅读本科生院通知及正文内容                 |
| 空教室   | 按日期、节次、校区和教学楼查询空闲教室           |
| 校历     | 查看当前及历史学年的校历                         |
| 寝室电费 | 绑定寝室并查询用电信息                           |
| 个性化   | 支持浅色、深色、减少动态效果、触感反馈和校园宠物 |
| 关于     | 艺术海报、近 13 周的个人上线砖墙与个人图片分享   |

### 关于页上线记录

每次小程序进入前台，为当前登录账号记录一次上线；未登录时进入，登录成功后补记一次。同一次前台停留期间，切换页面、心跳和重复登录不重复计数。记录按设备当地日期分组，按账号保存在本机，保留最近 400 天；关于页展示含本周的 13 周，以对齐的圆角方格和颜色表示每天的上线次数。上线记录从首次使用此版本开始，历史不做补填，未来日期留空。清除小程序数据会清除这些本机记录。

色阶按显示范围内已记录的不同正次数动态计算：零次始终使用底色，另有四档绿色，共五档。正次数不足四种时从最强绿色依次向下排；超过四种时，按不同次数的升序名次均分为四组，相同次数始终同色，最高次数始终为最强色。未来日期和显示范围外的记录不参与分档；页面的 13 周砖墙与分享图的 8 周砖墙共用分档规则，各自在可见日期内计算。

“已陪伴”使用服务端 `users.created_at` 对应的 `registeredAt`，转换为设备当地日期后计算至今天的自然日数，注册当天为第 1 天，跨夏令时不按小时折算。它不使用首次本机上线、入学或最近登录日期。旧会话通过已有个人资料预加载补齐字段，缺失时暂不显示天数；本机上线记录清除后，陪伴天数仍按账号首次注册时间计算。

右上角圆形按钮按当地日期和当前账号的砖墙生成 900 × 1350 PNG，再打开微信原生图片分享面板。个人海报下方左侧显示含本周的最近 8 周，右侧并排放置小程序码。图片不含姓名、学号、账号凭证或次数文字；分享给朋友时也附带小程序首页入口。不支持图片分享面板的客户端回退到图片预览。页面离开或账号切换后，不展示尚未完成的旧图片。

小程序码使用 `features/assets/mini-program-code.jpg`，由用户提供的 `gh_4c8dc19202ae_860.jpg` 重命名并移动而来，保留原始 860 × 860 JPEG。导出时以 260 × 260 正向绘制，使用 Canvas `multiply` 合成将白底融入海报纸色，保留黑色码点及完整轮廓，不裁剪或重绘码点。资源随功能分包离线提供，等待图片解码完成后再导出；加载失败或超时会结束加载状态并允许重试，不导出缺码海报。

图片使用离屏 Canvas 2D 绘制，不依赖 Skyline 页面内 Canvas；绘制尺寸不随设备像素比放大，导出后释放像素缓冲区。页面 SVG 与图片共用 `features/utils/about-art.ts` 中的轮廓，调整图形后运行 `node scripts/build-about-art.js` 更新资源。实现依据：[离屏画布](https://developers.weixin.qq.com/miniprogram/dev/api/canvas/wx.createOffscreenCanvas.html)、[图片分享](https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.showShareImageMenu.html)、[画布尺寸限制](https://developers.weixin.qq.com/miniprogram/dev/component/canvas.html)。

### 小程序转发

所有页面的右上角“··· → 转发给朋友”使用统一的原生小程序卡片：标题为“西小易 · 便利校园”，封面为 `assets/share/app-cover.jpg`（1000 × 800，5:4），打开后进入首页，由接收者自己的登录状态加载内容。分享参数不使用当前页面截图、用户资料或详情页参数；未登录、离线、深色模式和个人海报生成中均可直接返回同一张封面，无需等待图片生成或下载。

封面放在主包并通过 `packOptions.include` 显式保留，所有分包也可直接使用。每次小程序启动后的首次原生转发，将约 107 KiB 的成品封面复制到本地用户目录，供原生面板读取，之后复用；更换封面时更新本地文件名版本，避免原生缩略图缓存继续显示旧图。本地存储不可写时回退到代码包图片路径。原生转发与关于页圆形按钮的个人海报分享各自独立。实现依据：[onShareAppMessage](https://developers.weixin.qq.com/miniprogram/dev/reference/api/Page.html#onShareAppMessage-Object-object)、[copyFileSync](https://developers.weixin.qq.com/miniprogram/dev/api/file/FileSystemManager.copyFileSync.html)。

## 使用说明

登录校园账号后即可查看与本人相关的课程、成绩、考试等信息。部分功能依赖校园系统的开放状态；如数据存在差异，请以学校官方系统和通知为准。
